# Первый прогон 640×480

> Исторический эксперимент. После сравнения выбран минимум 800×600 для сборок Anbernic. Режим 640×480 больше не поддерживается; описание ключей и поведения ниже относится к указанной в validation.json прежней сборке.


Три снимка получены из работающего ARMHF-порта под QEMU, с лицензионными ресурсами 2.1.2500 и SDL software. PNG сохранены из BMP без изменения размера. В журнале игры: `Display Mode=640x480`.

- [Главное меню](menu.png).
- [Создание персонажа](character.png).
- [Космос](space.png): загружено прежнее тестовое автосохранение, выполнен вылет; космос отрисовывался 20 секунд.

Это первый эксперимент, а не завершённая адаптация: элементы HD-интерфейса обрезаются. Первый прогон новой кампании достиг станции, но упал при чтении отражения в ангаре вне framebuffer. После исправления границ копирования загрузка сохранения и вылет прошли успешно. Все три снимка сделаны одной итоговой сборкой; хеш и результаты — в validation.json.

Режим включается отдельно: `--experimental-low-res` и `VideoMode=640,480` в CFG.TXT. По умолчанию экспериментальный режим выключен. Аппаратный GPU и физическая приставка не проверялись; клавиатура и остальные экраны при 640×480 ещё не проверены. Публичные релизные пакеты не обновлялись.
