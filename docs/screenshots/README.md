# Скриншоты / Screenshots

Реальные кадры из ARMHF/AArch64 сборок через QEMU с SDL software renderer
и лицензированными ресурсами 2.1.2500. Физические приставки не проверялись.
Кадры относятся к бинарникам релиза `anbernic-keyboard-2026.10.11`.
