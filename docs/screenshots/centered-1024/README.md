# Центрирование оборудования в 800×600 и 1024×768

Окно оборудования корабля в космосе, включая полностью раскрытую правую
колонку, центрируется в области над HUD в обоих разрешениях. Раньше
центрирование включалось только ниже 1024 пикселей. На станции сохраняется
компоновка с сервисами и складом.

Проверка: загрузка кампании и цикл 800×600 → 1024×768 → 800×600 через
графические настройки в одном процессе. Оборудование открывается на каждом
этапе, после возврата также открывается карта галактики.

ARMHF: [800×600](armhf-ship-800.png), [1024×768](armhf-ship-1024.png),
[возврат в 800×600](armhf-ship-800-return.png), [отчёт](armhf-validation.json).

AArch64: [800×600](aarch64-ship-800.png), [1024×768](aarch64-ship-1024.png),
[возврат в 800×600](aarch64-ship-800-return.png), [отчёт](aarch64-validation.json).

Это реальные кадры SDL без изменения размера. Проверка проводится под QEMU
с SDL software/dummy; работа на физических приставках не проверена.
Отчёты фиксируют фактические разрешения, код завершения и SHA256 бинарников.
Изменения пока не включены в опубликованный релиз.
