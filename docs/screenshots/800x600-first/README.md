# Первый прогон 800×600

> Исторический эксперимент. После сравнения выбран минимум 800×600 для сборок Anbernic. Режим 640×480 больше не поддерживается; описание ключей и поведения ниже относится к указанной в validation.json прежней сборке.


Три снимка получены из работающего ARMHF-порта под QEMU, с лицензионными ресурсами 2.1.2500 и SDL software. PNG сохранены из BMP без изменения размера. В журнале игры: `Display Mode=800x600`; каждый снимок имеет размер 800×600.

- [Главное меню](menu.png).
- [Создание персонажа](character.png).
- [Космос](space.png): загружено прежнее тестовое автосохранение, выполнен вылет; космос отрисовывался 20 секунд.

Оба прогона завершились с кодом 0; снимки сделаны одной экспериментальной сборкой. Хеш и результаты сохранены в validation.json. Новая кампания при 800×600 не проверялась.

Интерфейс пока обрезается по краям. Требуется адаптация расположения панелей, прежде чем считать этот режим готовым. Режим включается отдельно: `--experimental-low-res` и `VideoMode=800,600` в CFG.TXT; запуск с `--windowed` обеспечивает точный размер кадра в этой тестовой среде. По умолчанию эксперимент выключен.

Физическая приставка и аппаратный GPU не проверялись. Клавиатура и остальные экраны при 800×600 ещё не проверены. Публичные релизные пакеты не обновлялись.
